# OG-card fonts

Static TTF subsets of the brand faces, vendored for the server-side share-card
renderer (`app/lib/og-card.server.ts`) — satori cannot consume the woff2 files
the site itself loads. Downloaded from Google Fonts; all three families are
licensed under the SIL Open Font License 1.1:

- Newsreader 500 (Production Type)
- DM Sans 400 (Colophon Foundry / Jonny Pinhorn)
- JetBrains Mono 500 (JetBrains)
