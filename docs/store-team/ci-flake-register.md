# CI flake / endemic-failure register

One row per check that fails for reasons unrelated to the PR that trips it —
endemic (fails on main / across unrelated branches) or genuinely flaky
(non-deterministic, passes on a bare re-run). Diagnosed once here, then
cited rather than re-investigated on every PR that hits it. Maintained by
R-SHEP (`.claude/agents/pr-shepherd.md`); see its `<flake_register>` section
for the process.

| `check` (vitest) | 2026-09-01 (PR #1012, PR #1011, PR #1010, same day) | `app/lib/storefront-home.server.test.ts > assembleStorefrontHome — pinned-headliner out-of-stock gate > "does not pin a tracked zero-stock product found only via the raw index lookup"` fails non-deterministically: `AssertionError: expected 'y' to be 'x'` at line ~448 (`expect(data.featured[0]!.handle).toBe('x')`), roughly half of all runs. Root cause: the test never mocks `Date.now()` or seeds the rail shuffle, so `hydrateStorefrontPayloadB`'s `reshuffleRailsWithSeed(payload.rails, railSeedBucket())` (`app/lib/storefront-home.server.ts`) shuffles the two-item mocked rail `[x, y]` using the real wall-clock 15-minute bucket (`RAIL_SEED_BUCKET_MS = 900_000`) fed through the `mulberry32` PRNG in `app/lib/homepage-payload.server.ts`. Which item lands in `featured[0]` is therefore a coin flip on the current bucket, unrelated to any PR's diff — including main's own. | Reproduced on three unrelated open PRs (#1012, #1011, #1010; base sha `ba20d8d`) whose diffs touch `app/lib/social-admin-rework.server.ts`, `app/lib/team-gates.server.ts`/`emma-voice.server.ts`/social routes, and `app/lib/video-episodes.server.ts` respectively — none touch `storefront-home.server.ts`, its test, or `homepage-payload.server.ts`. A standalone Node simulation of `railSeedBucket()` + `mulberry32` across 2000 consecutive 15-minute buckets landed `x` first ~50.3% of the time and `y` first ~49.7% — a true coin flip, not a rare edge case. The test passes when run against current main HEAD (`24184e1`) at some wall-clock moments and would fail at others, by design of the mechanism above; it is not a regression introduced by any commit.
